# Aditya Kashyap — Portfolio

A responsive React + Vite + Tailwind CSS portfolio starter.

## Run locally
1. Install .js (LTS).
2. Extract this folder and open a terminal inside it.
3. Run `npm install`
4. Run `npm run dev`
5. Open the local URL printed by Vite.

## Personalise before publishing
Open `src/main.jsx`:
- Replace `PROFILE.email`, `PROFILE.linkedin`, and `PROFILE.github` with your real details.
- Replace the initials-based visual in the hero with your own portrait if desired.
- Replace the education placeholder with your actual degree, institution and year.
- Update project preview images and `url` values to your real live demos / case studies.
- The contact form uses `mailto:` and opens the visitor's email application. For server-side form delivery, connect a form backend.

## Build for deployment
Run `npm run build`; deploy the generated `dist/` directory to Vercel, Netlify, or another static host.
